# 战斗优化 v2

在原版和旧必杀宽松版之外增加 `public/game/combat/`。默认选择“战斗优化”，改变选择后重新启动应用，原版保留可对比。

## 大招输入历史

此前只延长原隐藏识别时间轴，仍要求回中与攻击落在特定帧。本版额外在三名角色的根帧回调中记录实际按键历史，保留原回调，不重编译原角色脚本。新增辅助代码由既有FFDec26.4.0的AS2编译器单独编译为AVM1，再添加到角色第一帧。

- 下下上：两次独立下方向按下，每步最多750ms，上方向允许斜上；上之后450ms内可补按攻击，无需上方向与攻击同帧。
- 最终大招：下→前→下→前，经过下前斜方向不算错误；最后方向之后450ms内补攻击。支持左右镜像，第二次前方向必须与第一次一致，每步间隔最多750ms。
- 完成长按下不会冒充两次下方向；超时清除。暂停、空中、受击、死亡等状态不缓存大招。允许原子剪辑在同帧把最后一次J先作为普通地面攻击处理后，转交给已准备好的大招，但必须上一帧为可操作地面状态。
- 不自动放招，也不代按方向序列。龙出仍需100MP，乱舞仍需130MP；原版初始上限100，升级提高MP上限。辅助识别只跳入原大招入口，由原动画执行扣费，避免重复扣费。

对应实现为 `scripts/combat-command-assist.as`，编译器入口为 `scripts/CompileAvm1.java`。输入历史单元检查直接执行同一份AS2兼容JavaScript源，包含延迟补攻、斜方向、镜像、超时、按住、低MP、暂停与原子剪辑先消费攻击的顺序回归；不能将这些模拟测试视为手机实测成功率。

## 移动端独立起手按钮

提供飞空、鬼步、龙出、乱舞四个按钮，分别使用内部扩展键1/2/3/4进入原招式标签。前两者免费，大招仍受100/130MP门槛限制。按住只起手一次，不自动循环，不在受击或无关技能中强行取消。旧版本模式禁用这四个按钮。

飞空中的原 `frame_119/.../onClipEvent(enterFrame)` 仍检测“下＋新按攻击”并转入飞空2；现在也可在飞空中再点同一按钮下劈。鬼步起手使用鬼步1原入口，其过程中再点鬼步按钮接鬼步2，再点接鬼步3，也保留原方向＋攻击衔接。每次点击只推进一段，不代放整套连招。

太早点下一次时暂存600ms：飞空至少播放到原第119帧，鬼步1至少播放到188帧，鬼步2至少播放到203帧，才进入下一段。鬼步1、2攻击框分别在186、201帧出现，因此不会因连点而直接跳过当前段命中动作。暂停、死亡、阶段结束清掉待衔接请求，不自动推进段数。按钮MP不足或角色忙碌时，页面会显示原因。

按主动主招式入口计8项：特殊技、冲击、飞空、鬼步1/2/3、龙出、乱舞；飞空2等属于派生动作。普通三连、保护、抓投另算，不将28个动画标签直接当成28种技能。

## 有效命中回MP

原版普通h1/h2/h3与ts/ts1命中回1MP，大多数小必杀不回。现在对敌人/Boss的真实伤害分支统一为每次有效命中恢复5MP，`Math.min(maxmp,mp+5)` 截断；不另加按时间自动恢复。

检查21个敌人碰撞脚本，重编译其中20个伤害脚本、220个普通/小必杀命中分支；98处旧+1被替换。Boss防御状态的11个无伤害碰撞分支保持不回蓝。空挥、打箱子、破坏物、大招、火焰和投掷分支不增加回蓝。恢复是按每个敌人的有效命中计数，多目标命中可以多次回蓝。

`scripts/patch-hit-mp.mjs` 只导入所选脚本，之后重新反编译产物逐项检查220处恢复语句和防御状态排除。不导入整个反编译目录。来源例：原始 `export/scripts/DefineSprite_113_e_01/frame_2/PlaceObject2_23_8/CLIPACTIONRECORD onClipEvent(enterFrame).as`。

## 玩家攻击框

只修改角色根时间轴的具名攻击实例 `h1/h2/h3/ts/ts1/b_cj/b_fk/b_fk3/b_gb1/b_gb2/b_gb3` 的PlaceObject2矩阵：横向×1.25、纵向×1.15。保持判定框中心，按共同原始形状中心(-0.5,0)像素补偿translation。

三名角色分别14、14、15个实例，共43处。没有放大共享形状、角色本体、角色受击框、敌人攻击框或大招范围，也没有延长攻击动画。构建清单保存每一处修改前后矩阵。

## 构建与验证

先有 `npm run patch:specials` 生成的旧必杀宽松资源，然后运行 `npm run patch:combat`。需要Java17及仓库既有FFDec；可通过 `JAVA_COMMAND` 指定Java路径。正常 `npm run build` 直接复制已提交的产物，不依赖Java。

测试验证新增辅助代码哈希、43处矩阵及非目标角色标签保持一致；另检查输入边界、MP恢复白名单与Boss格挡排除。原版、普通连击宽松、旧必杀宽松的检查继续保留。真实设备的技能触发率、击中手感和MP平衡需要实际游玩反馈。

运行时已用临时只读trace探针验证1号角色：下100ms、松开180ms、下100ms、松开120ms、上80ms、松开200ms后按攻击，日志显示从第14帧将同次普通攻击转交给龙出，原大招扣费后暂停面板MP为0/100。该结果确认了真实AVM1中的同帧回调顺序兼容，不只依赖模拟测试。探针已通过重新构建移除，发布产物仅保留供页面反馈使用的技能消息。
